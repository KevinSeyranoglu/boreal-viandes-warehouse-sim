ECC COMMANDS - QUICK REFERENCE
==============================

PLANNING (before any code)
--------------------------
/ecc:plan <idea>            Plan + confirmation step. Writes no code until you say yes.
/ecc:plan-prd <idea>        Short requirements doc saved to a file; /ecc:plan can use it.
/ecc:prp-plan               Detailed plan file for big features...
/ecc:prp-implement          ...then builds it with validation at each step.

BUILDING
--------
/ecc:orch-build-mvp <spec>  Builds a first working version from a spec file, in slices.
/ecc:feature-dev <feature>  Adds one feature to existing code ("add the recall event").
/ecc:orch-fix-defect <bug>  Reproduces a bug with a test first, then fixes it.
/ecc:build-fix              Use when it crashes on startup or on import.

CHECKING QUALITY
----------------
/ecc:python-review          Python review (PEP 8, type hints, idioms). Run after each phase.
/ecc:code-review            General review of your uncommitted changes.
/ecc:checkpoint             Records a verified "phase X works" checkpoint.

SAVING TOKENS AND CONTEXT
-------------------------
/ecc:save-session           Save where you are before stopping for the day.
/ecc:resume-session         Pick up later without re-explaining everything.
/ecc:aside <question>       Quick side question without derailing the current task.
/ecc:context-budget         Check when a long session is getting heavy.
/ecc:model-route            Big model or a cheaper one for this task?
/ecc:ecc-guide              Browse everything ECC offers.

GOOD WORKFLOW FOR THIS PROJECT
------------------------------
1. Keep the full spec in SPEC.md. Then just say "build Phase 2 from SPEC.md"
   instead of pasting the whole thing again.
2. One phase per prompt ("build phase 1 only"), then try it.
3. /ecc:python-review after each phase.
4. /ecc:save-session before you stop.

TIPS
----
- You don't need "give me the complete code file by file": Claude Code writes
  the files directly into the folder and runs them.
- The GateGuard hook makes Claude state facts before its first shell command
  or new file each session. To skip that for routine commands, set:
      GATEGUARD_BASH_ROUTINE_DISABLED=1
  (checks on destructive commands stay on)
